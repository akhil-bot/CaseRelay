Process Flow · CR-1042 Maya (hop-by-hop)

1 · Intake & Draft

Intake Agent extracts 5 commitments + referrals from synthetic packet; case stays draft — no grants yet
cases:W draft commitments:W ×5 referrals:W ×5

2 · Activate & Grant

Supervisor approves; authority_grants written per agent purpose; cases status → active
cases: active authority_grants:W allowed: name, dob, referral_id

3 · Orchestrate & Sleep

Reads agent_cards; Pub/Sub fan-out to 5 domain agents; checkpoints workflow; schedules day-17 wake
agent_cards:R workflow_checkpoints:W Pub/Sub fan-out

4 · Gateway + Model Armor

Projects fields per grant (Education: name/dob only); poisoned school payload quarantined; escalation drafted
audit_events:W disclosed/withheld policy_decisions: quarantine human_approvals: pending

5 · Day-17 Wake & Complete

Cloud Tasks fires; enrollment callback idempotent via idempotency_key; education commitment → completed
partner_updates:W idempotent commitments: completed audit_events: completion
Pub/Sub events · Cloud Tasks schedule · Firestore reads & writes
